# Smart Parking Slot Booking System (DevOps Lab Project)

Simple Java Maven project for Software Engineering and DevOps lab.

## Features
- Add and manage parking slots
- Book available slots
- Cancel bookings
- Unit tests with JUnit
- Docker, Jenkins, and Ansible configuration

## Run locally
1. Install Java 11 and Maven
2. Build and test:
   - `mvn clean test`
3. Package:
   - `mvn package`
4. Run:
   - `java -jar target/smart-parking-slot-booking-system-1.0-SNAPSHOT.jar`
